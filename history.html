フリーランス期（2023 – 2026）

独立後はPOS・決済端末の開発に参画し、生成AIの実務活用へ。

    POSシステムで使用するモジュールのテスト作業を、生成AIで効率化・自動化するシステムの考案・開発。ローカルLLMの知見を深めながら、業務効率化ソリューションの提案も担当。

    C/C++/C# · 組み込みWindows · Claude Code · VMware · GitHub

  • 決済端末開発 2025.10 – 2026.03

    非接触ICクレジット機能移植の設計・製造・テスト。Unity/CMockによるテスト自動化や、生成AI（プロンプトエンジニアリング）を活用した作業効率化を実践。

    C · 組み込みLinux · Unity/CMock · Claude Code

  • 次期POSシステム開発（電子マネー） 2024.06 – 2025.09

    POS本体の電子マネー決済まわりの設計・製造・テスト（全体約100名規模）。VB.NET / Microsoft SQL Server による.NET開発の知見を獲得。

    VB.NET · VB6 · SQL Server · PowerShell · 組み込みWindows10

  • 携帯決済端末（Handy Terminal）アプリ開発 2023.12 – 2024.05

    Android端末向け決済アプリの設計・製造・テスト。Java によるAndroidアプリ開発を担当。

    Java · Android · SQLite · Android Studio

  • 次期POSシステム開発（設計） 2023.07 – 2023.11

    独立後最初の案件。ガソリンスタンド向け次期POSの設計を担当。前任者不在の中、散在した資料を集めて設計書を作成するところから対応。

    基本設計 · ドキュメント整備

  • 車載機器 画面表示ソフトウェア開発 2023.04 – 2023.06

    メーターUIの画面遷移・スイッチ操作を調停するライブラリの修正、仕様追加対応。他コーダー成果物のレビューも担当。

    C · AUTOSAR CP · MISRA C 2004/2012 · CERT-C · QAC/HelixQAC/Polyspace · ISO26262 · A-SPICE

  • 業務プロセス改善 2020.07 – 2023.03（兼務）

    改善ワーキンググループを立ち上げ、Git / GitLab / Jenkins の導入・定着、改善用ツール群の開発・保守を推進。「提案」で終わらせず、社内文化を変えて浸透させるところまで実行。

    Git/GitLab · Jenkins · PowerShell · Perl · Python

  • 車載機器 制御ソフトウェア開発 2014.12 – 2015.06

    割り当て機能の設計・製造・テスト（仕様変更対応）。独自OSと体系化された開発プロセスの知見を獲得。

    C · 独自OS · MISRA C 2004 · QAC

  • 基板作成機器（マウンター）の制御アプリ開発 2013.12 – 2014.06

    静岡移住後最初の案件。機器制御ソフトと機器管理アプリの仕様変更対応。

    C · WindowsCE · VisualC++
